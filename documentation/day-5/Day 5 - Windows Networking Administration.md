# Day 5 - Windows Networking Administration

## Objective
Learn how Windows networking works in real environments, including IP configuration, DNS troubleshooting, SMB shares and mapped network drives.

---

# Topics Covered

- DHCP vs Static IP
- IPv4 configuration
- DNS manual configuration
- DNS troubleshooting
- Network adapters
- SMB shares
- UNC paths
- Mapped network drives
- Localhost testing
- Network share troubleshooting
