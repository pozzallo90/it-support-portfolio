# Day 2 - Windows Basics & Networking

## Objective
Learn Windows basics and understand how a computer communicates on a network.

---

## Commands Used

### hostname
Shows the computer name.

### whoami
Shows the currently logged in user.

### ipconfig
Displays the network configuration.

### ping google.com
Tests internet connectivity and DNS resolution.

---

## What I Learned

### Hostname
Every computer has a unique name used for identification in a network.

### IP Address
An IP address identifies a computer inside a network.

### DNS
DNS translates names like google.com into IP addresses.

### Task Manager
Task Manager is used to monitor CPU, RAM and processes.

### Network Adapter
The network adapter allows the computer to communicate with the network.
